# MIT 8103 – Advanced Database Systems

## SwiftPay Digital Banking System

**Student ID:** 301918044  
**Project:** SwiftPay Digital Banking System  
**Database Technologies:** PostgreSQL and MongoDB

## 1. Project Overview

This project presents the design and implementation of a simulated Nigerian fintech banking platform called SwiftPay. The system demonstrates database design, SQL query processing, transaction management, concurrency control, NoSQL data modelling, and distributed database architecture.

The project uses PostgreSQL for structured banking data and MongoDB for flexible transaction documents.

## 2. Tools and Technologies

- PostgreSQL 18
- pgAdmin 4
- MongoDB Community Server 8.0
- MongoDB Compass
- Mermaid Live Editor
- GitHub

## 3. Portfolio Structure

### Portfolio 1 – Database Design and Modelling
Contains the SwiftPay entity relationship diagram, relational database schema, SQL implementation, tables, keys, and constraints.

### Portfolio 2 – Query Processing and Optimisation
Contains SQL queries, transaction summaries, joins, execution plans, and database indexing evidence.

### Portfolio 3 – Transactions and Concurrency
Demonstrates COMMIT, ROLLBACK, transaction isolation, read committed behaviour, and concurrency control using row locking.

### Portfolio 4 – NoSQL and Advanced Data Models
Demonstrates MongoDB database and collection creation, document insertion, filtering, and aggregation.

### Portfolio 5 – Distributed and Cloud Database Exercise
Presents a proposed distributed database architecture involving PostgreSQL primary-replica replication and MongoDB transaction storage. The architecture is a design proposal, not a deployed distributed environment.

## 4. How to Review the Project

Each portfolio has its own folder containing relevant documentation, implementation files, diagrams, and screenshots.

The PostgreSQL SQL script in Portfolio 1 can be reviewed to understand the relational database implementation. The MongoDB evidence in Portfolio 4 demonstrates the NoSQL implementation.

## 5. Conclusion

The SwiftPay project demonstrates the application of relational and NoSQL database technologies to a simulated digital banking environment. It also explores transaction reliability, query optimisation, concurrency management, and distributed database design.
